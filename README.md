# Hoedt Coaching — coach-portaal (frontend-snapshot)

De volledige coach-webapp zoals die nu draait, statisch weggeschreven met voorbeelddata.
Bedoeld als visuele basis om de UI te herontwerpen.

- **20 pagina's**, allemaal gestyled en klikbaar. Start op `/`.
- **Knoppen die opslaan doen niets** — er zit geen backend onder. Dit is een referentie, geen werkende app.
- Styling zit in `styles.css` + `css/` (design-tokens, hoedt-skin, mobile). Daar gebeurt het meeste werk.

## Wil je het écht werkend?
Draai de echte repo lokaal — dan werken alle knoppen, data en interacties:
`git clone` de backend-repo → `npm install` → `node server.js` → http://localhost:3000/coach
